# gbot: вероятностный торговый бот (Binance USD-M, M1/M5)

Исследовательский каркас. Признаки SMC и Вайкоффа, решение по матожиданию, жёсткие лимиты риска.
План проекта: https://claude.ai/artifact/Gy9dNkdJM8M4cCnQZ4jR4G

## Быстрый старт

```bash
pip install -e .[dev]
pytest
gbot universe                 # вселенная инструментов на сегодня -> reports/universe-YYYY-MM-DD.csv
gbot universe --symbols BTCUSDT ETHUSDT SOLUSDT
```

История берётся из публичного архива `data.binance.vision`, ключи API не нужны. Кэш хранится в `data/raw/`.

## Что есть сейчас

| Модуль | Что делает |
|---|---|
| `config/settings.toml` | Капитал, лимиты риска, комиссии, пороги ликвидности. Модель их не меняет |
| `gbot/data/binance_vision.py` | Список всех perpetual-контрактов (включая делистингованные), загрузка свечей и `bookDepth` |
| `gbot/universe.py` | Фильтр ликвидности: cost ratio, минимальный допустимый стоп, глубина ±0.2%, участие в объёме, кластеры корреляции |
| `gbot/risk.py` | Размер позиции (¼ Келли с потолками), лимиты на сделку, кластер, портфель и плечо, дневной, недельный стоп и стоп по просадке |

## Главная метрика ликвидности

`cost ratio = (спред + комиссии + проскальзывание) / медианный ATR(5m)`.

Риск-менеджер отклоняет сделку, если издержки больше 25% её риска. Поэтому `cost_ratio / 0.25` — это минимальный стоп в единицах ATR(5m).
Класс A: минимальный стоп не больше 2 ATR(5m). Класс B: не больше 3 ATR(5m). Класс C: не торгуем.

Спред пока оценивается по свечам (оценка Abdi–Ranaldo, с полом 0.5 б.п.). Когда бот будет собирать живой `bookTicker`, оценку заменят реальные данные.
